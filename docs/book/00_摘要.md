# 摘要

大模型让"随时能问、随时有答"成为现实，但直接把通用大模型当老师用，暴露出四类共性问题：回答千篇一律、不因人而异；学生问什么答什么、直接给答案，反而削弱独立思考；对话结束即失忆，每次学习都从零开始；学习路径推荐是黑盒，师生看不懂、难信任。针对上述问题，本项目研发了面向高校人工智能专业《机器学习》课程的伴学智能体"知途伴学"，以"教育学正确性优先、可解释性优先、可私有化部署优先"为原则，将命题要求的四大能力逐一落地：①学情诊断——对话与自适应测验双通道采集学情，以"BKT 简化 + Elo 自适应学习率"显式公式实时更新掌握度，构建并持续修正学生画像；②路径规划——基于 50 知识点、81 条先修关系的自建知识图谱，融合拓扑分层、ZPD 最近发展区难度带与节奏参数动态生成学习路径，并由大模型在公式候选集内完成定序与理由生成，实现可解释的自适应决策；③实时干预——以"苏格拉底反问→概念提示→类比样例→分步解析＋变式检验"四级脚手架逐级引导，只引导不代答，干预内容锚定题库与讲义原文，从机制上抑制大模型幻觉；④记忆与反思——以 SQLite 9 表沉淀跨会话长期记忆，会话结束生成反思摘要，下一次对话自动延续学习进度。系统采用 OpenAI 兼容 LLM 抽象层：已接入讯飞开放平台星火 Lite 永久免费额度并实测联调通过（2026-09-14），无 API Key 时自动降级离线 Mock，断网环境下全功能可运行、可私有化部署、数据不出校。全系统 107 项 pytest 自动化用例全部通过，验证了知识图谱无环、掌握度公式单调性、路径落在 ZPD 带内、脚手架逐级升级与跨会话记忆延续等全部核心承诺。本项目以零成本、可解释、可私有化的工程形态，把"千人一面"的课程学习升级为"诊断—规划—干预—反思"闭环的个性化学习，是对"从被动答疑到主动引导"教育范式跃迁的一次可运行、可验证的实践。

**关键词**：大模型；自适应学习；学习路径规划；脚手架式干预；知识追踪；伴学智能体
