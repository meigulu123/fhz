# 命题九十六：大模型驱动的自适应学习路径决策与伴学智能体开发（原文）

> 命题企业：科大讯飞（注：按用户要求，UI 与宣传物料中不出现企业名，仅文档使用）

## 一、命题背景

在个性化教育需求爆发的当下，传统的"千人一面"教学模式已难以满足学生多元化的学习需求。虽然知识图谱与推荐算法已应用多年，但缺乏灵活的交互能力与深层推理能力，难以实现真正意义上的因材施教。大模型智能体的出现，为构建"既懂知识又懂学生"的AI导师提供了可能。本命题旨在鼓励开发者利用大模型与Agent技术，构建具备感知、规划、行动能力的智能伴学应用，实现从"被动答疑"到"主动引导"的教育范式跃迁。

## 二、命题内容

本命题要求参赛团队设计并实现一个面向特定学科专业（如人工智能、电子信息、计算机等）的"自适应学习伴学智能体"。该智能体需具备以下核心能力：

1. **学情诊断**：能够通过自然语言对话或测试，动态分析学生的知识掌握情况与认知水平，构建精准的学生画像。
2. **路径规划**：基于学生画像与知识图谱，动态生成个性化的学习路径，支持学习顺序、内容难度与学习节奏的智能适配。
3. **实时干预**：在学生遇到困难时，提供针对性的脚手架式辅导，而非直接给出答案，培养学生独立解决问题的能力。
4. **记忆与反思**：智能体应具备跨会话的长期记忆能力，够在多次交互中持续记录学习进展，并基于历史数据反思与优化后续学习计划。

## 三、答题要求

1. 参赛项目应站在命题企业的角度解读命题，充分调研命题背后的市场需求，与命题企业做好充分对接，思考项目团队与命题企业未来的合作模式。
2. 参赛团队提交内容应包括商业计划书、源代码或可运行的演示Demo、演示视频（3-5分钟，展示智能体与用户交互等的过程）。需详细阐述智能体的技术架构、所使用的知识库构建方式，以及如何利用大模型实现动态路径优化。如有涉密及敏感性信息等，可以根据实际情况调整删改后提交计划书。
3. 项目方案内容应满足《产业命题赛道项目评审要点》规定的各项要求，按照大赛总体要求提供网评材料，提前做好路演准备。
